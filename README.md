 # 🎓 Teacher's Day Tribute Website

 LIVE VIEW: https://libunagomer26-spec.github.io/GRETINGS-TO-INTRUCTOR/

> A modern digital Teacher's Day greeting created for **Sir Randy Bello**, Web Development Instructor.

## ✨ Overview

This project is a personalized Teacher's Day tribute website designed with a modern developer-inspired interface. It combines appreciation, creativity, and web development skills into a single interactive webpage.

## 🚀 Features

* 🎨 Modern responsive design
* 🌙 Dark / Light mode toggle
* 💌 Interactive greeting card animation
* 📱 Mobile-friendly layout
* ✨ Smooth transitions and effects
* 🖼️ Instructor profile section
* 🎓 Personalized Teacher's Day message

## 📂 Project Structure

```text
project/
│
├── index.html
├── style.css
├── script.js
├── teacher.jpg
└── README.md
```

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts (Inter & Space Mono)

## 🎯 How to Run

1. Download or clone the repository.
2. Make sure `teacher.jpg` is in the project folder.
3. Open `index.html` in your browser.
4. Click **OPEN MESSAGE** or press **Enter** to reveal the animation.
